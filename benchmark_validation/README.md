# PhosphoFill strip-and-regraft benchmark

This directory freezes the corrected TPO, SEP, and PTR benchmark completed on
27 August 2026. Source files were copied from `Benchmark_combined_final`; the
working files were not moved or modified.

## Scope

The benchmark strips phosphate atoms from experimental phosphoresidues,
regrafts the phosphate with PhosphoFill, and measures permutation-invariant
phosphate RMSD against the corresponding experimental phosphate coordinates.
The package contains the exact scripts, benchmark definitions, raw output,
processed output, manuscript tables, and Figure 3 generated by the completed
run.

## Scripts used

- `scripts/frozen/run_corrected_benchmark.py`: original orchestration script.
- `scripts/frozen/phosphofill_benchmark_production.py`: downloads/loads the
  experimental structure, records reference phosphate coordinates, strips the
  phosphate, calls the grafting code, and measures all RMSDs.
- `scripts/frozen/graft_phospho_openmm_production.py`: internal-coordinate
  phosphate construction, 12-by-30-degree prescan, ranking, and OpenMM local
  minimisation.
- `scripts/frozen/phosphofill_report_v4_modes_geom.py`: per-pose structural and
  environmental reporting.
- `scripts/frozen/analyse_benchmark_postmin.py`: applies the primary-residue and
  `status=OK` filters and creates Figure 3, Tables 2-3, and summary statistics.
- `scripts/run_benchmark.py`: portable wrapper that preserves the frozen code
  but adapts paths to this directory structure.

## Benchmark stages

1. **S0 seed:** phosphate placement using the residue-specific internal-coordinate
   seed, without prescan or minimisation.
2. **S1 oracle:** lowest experimental-coordinate RMSD among the 12 scanned
   orientations. This is an evaluation ceiling and is not used for selection.
3. **S2 selected:** pose selected by PhosphoFill scoring before minimisation.
4. **S3 top-1:** highest-ranked pose after OpenMM minimisation.
5. **Best of three:** lowest RMSD among three ranked poses that were each
   independently reconstructed and minimised.

For multi-site structures, sites are sorted N-to-C. Prescanning is sequential on
the accumulating grafted model, so later sites see earlier rank-1 phosphates.
After all sites have been scanned, each pose rank is reconstructed and its sites
are minimised sequentially N-to-C with coordinate updates retained. The command
label `--graft-mode joint` means that all context sites are supplied in one run;
it does **not** mean a single simultaneous OpenMM minimisation of all sites.

## Frozen empirical priors

| Residue | Anchor-P (Å) | Valence angle | Torsion seed/prior |
|---|---:|---:|---|
| TPO | 1.613 | 118.8° | −58.9° |
| SEP | 1.614 | 115.4° | primary seed +66.3°; additional seeds +12.6° and −45.0°; broad scoring basin [−60°, +50°] |
| PTR | 1.609 | 125.1° | neutral 0° seed; no torsion-prior penalty |

The prescan uses a 30° increment, producing 12 orientations. The completed run
used `--prescan-contact-weight 0.0`, `--prescan-pack-weight 0.2`,
`--graft-mode joint`, and checkpointing after every benchmark input row.

## Inputs

The three TSVs in `inputs/benchmark_definitions` are the benchmark case
definitions. The three files in `inputs/ccd_templates` are the exact local CCD
templates used by the grafting script.

Experimental mmCIF structures were downloaded from the RCSB PDB and cached
locally. The original cache contains 1,018 files (832,990,574 bytes; about
0.78 GiB), so it is not duplicated in this compact benchmark package. Its file
sizes and SHA-256 hashes are frozen in
`inputs/manifests/structure_cache_manifest.json`. A fresh run downloads missing
structures automatically.

One original cached file, PDB 3BLH, was not valid UTF-8 and produced the recorded
TPO `ERROR` row. A fresh download may therefore process that case rather than
reproduce this transient cache failure. The frozen output preserves exactly what
the completed run reported.

`/home/paddy/venvs/ptm/bin/python`. Exact scientific-package versions are pinned

The manuscript analysis filters each raw file to `status=OK` and to its primary
residue type. Mixed-residue context rows remain in the raw outputs but are not
double-counted in the primary cohort.

|---|---:|---:|---:|---:|---:|
| TPO | 494 | 332 | 162 | 0.424 Å | 0.416 Å |
| SEP | 300 | 241 | 59 | 0.553 Å | 0.471 Å |

Across the 790 single-site cases, best-of-three recovery is 84.6% within 1.0 Å

independently measured after minimisation.

## Reference-run audit

The TPO, SEP, and PTR files in `outputs/raw` are byte-identical copies of the
completed reference run. The original working files remain unchanged.

For every primary-residue `status=OK` row, the benchmark output contains
`rank1_postmin_rmsd`, `rank2_postmin_rmsd`, and `rank3_postmin_rmsd`. The
grafting code reconstructs each pose rank from its absolute prescan coordinates
and performs a separate OpenMM minimisation pass for that rank. The verification
script found no missing rank values among the 1,284 primary successful sites.

For all 1,284 primary successful sites, `top3_best_postmin_rmsd` equals the
minimum of the three independently minimised rank RMSDs, and
`top3_best_postmin_rank` identifies a rank attaining that minimum. No mismatches
were detected.

Reference phosphate coordinates are read from the experimental phosphoresidue
before stripping. Each predicted pose is then compared with the corresponding
site in that same experimental structure using permutation-invariant phosphate
RMSD over P and the terminal phosphate oxygens.

The current output contains six valid multi-site records that were absent from
the earlier TSVs:

|---|---|---|---|---:|---:|
| SEP | P26361 | 1R0Z | C | 422 | 1.4563 |
| SEP | P26361 | 1R0Z | C | 660 | 2.8858 |

These are bookkeeping recoveries, not newly improved structural placements.
The earlier archive already contains the same rank-1 coordinates and exactly

contain sites without usable experimental phosphate coordinates: 1R0Z C659,
1R0Z C670, 1R0Z D659, and 2ZM3 A1161. The earlier archive stops before completing
the stage export and no rows from those benchmark cases were appended to the old
TSVs. The current run, performed without full structure archiving, retains the
valid sites and records only the unresolved sites as `NO_COORDS`.

## Verification

`scripts/verify_frozen_benchmark.py` checks raw row/status counts, primary-site
filtering, duplicate keys, single-/multi-site denominators, the presence and
internal consistency of all three post-minimisation RMSDs, summary medians, and
the empirical constants embedded in the frozen grafting code. Its latest report
is stored in `verification/benchmark_verification.json`.

`verification/SHA256SUMS` freezes the copied scripts, inputs, raw/processed
outputs, and plots. Recalculate hashes only when intentionally creating a new
benchmark release.
